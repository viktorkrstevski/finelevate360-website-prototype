A classic WordPress widget with Title, Text, and Image upload (via Media Library).

== Installation ==
1. Upload the plugin ZIP in Plugins → Add New → Upload Plugin.
2. Activate it.
3. Go to Appearance → Widgets and add: "Title / Text / Image (Custom)".
